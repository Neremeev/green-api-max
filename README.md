# GREEN-API Chat

Тестовое задание на позицию **Frontend разработчик React**.

Мессенджер для отправки и получения текстовых сообщений через сервис **GREEN-API** (поддерживает мессенджеры MAX / WhatsApp / Telegram). Интерфейс выполнен в виде веб-чата (по образцу `web.whatsapp.com`).

## Возможности

- Вход по учётным данным GREEN-API (`idInstance`, `apiTokenInstance`)
- Создание нового чата по номеру телефона
- Отправка текстовых сообщений (метод `SendMessage`)
- Получение входящих сообщений (технология HTTP API — long polling)
- Отображение статуса отправки (часы / одна галочка / ошибка)
- Несколько чатов, автоскролл к новым сообщениям

## Стек

- **React 18** + **TypeScript**
- **Vite** (сборка и dev-сервер)
- Работа с API — нативный `fetch` (без дополнительных библиотек)

## Как запустить локально

Требуется **Node.js 18+** и **npm/yarn/pnpm**.

```bash
# 1. Установить зависимости
npm install
# или yarn / pnpm install

# 2. Запустить dev-сервер
npm run dev
```

Откройте `http://localhost:3000`.

### Сборка для продакшена

```bash
npm run build      # соберёт в папку dist/
npm run preview    # локальный предпросмотр продакшен-сборки
```

## Как пользоваться

1. Откройте приложение. Нажмите **«Начать чат»**.
2. Введите учётные данные из личного кабинета **GREEN-API**: `idInstance` и `apiTokenInstance`.
3. Нажмите **«Подключиться»**.
4. В открывшемся окне введите **номер телефона получателя** в формате `7XXXXXXXXXX` и создайте чат.
5. Отправьте текстовое сообщение.
6. Ответы от собеседника будут появляться в чате автоматически (long polling).

> **Тестовая проверка:** чтобы увидеть входящее сообщение, можете отправить себе сообщение из другого аккаунта / телефона в тот же мессенджер (MAX / WhatsApp), который привязан к вашему экземпляру GREEN-API.

## Где взять учётные данные GREEN-API

1. Зарегистрируйтесь на https://green-api.com
2. Создайте экземпляр (`instance`) в личном кабинете
3. Скопируйте **idInstance** и **apiTokenInstance**
4. Привяжите номер телефона к мессенджеру (сканируйте QR-код)

## Структура проекта

```
src/
  api/greenApi.ts       # клиент GREEN-API (sendMessage, receiveNotification)
  hooks/useChat.ts      # основная логика: состояние, long polling
  components/           # UI-компоненты
  utils/chatUtils.ts    # нормализация телефона, форматирование
  types.ts              # типы
  App.tsx               # корневой компонент
  main.tsx              # точка входа
```

## Примечание про CORS

Запросы к GREEN-API выполняются напрямую из браузера. Публичный хост `api.green-api.com` отдаёт заголовки CORS, поэтому в dev-режиме дополнительный прокси не требуется.
